# Интерактивная лестница навыков

Десять уровней с подробными пояснениями простыми словами. На компьютере описания плавно появляются при наведении на ступень. На узком экране уровни раскрываются нажатием под изображением.

## Что находится в папке

- `index.html` – готовая страница, оформление и работа всплывающих карточек.
- `staircase.png` – изображение лестницы.
- `README.md` – эта инструкция.

## Как опубликовать на GitHub Pages

1. Распакуйте архив на компьютере.
2. Создайте на GitHub отдельный репозиторий, например `ai-skills-ladder`. Для бесплатного размещения выберите **Public** и добавьте README при создании.
3. Откройте репозиторий и выберите **Add file → Upload files**. Загрузите три файла из распакованной папки. Файл `index.html` должен находиться в корне репозитория, рядом со `staircase.png`.
4. Сохраните загруженные файлы в основной ветке `main` кнопкой **Commit changes**. Если GitHub предложит отдельную ветку, после сохранения объедините её с `main`.
5. Перейдите в **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
6. Укажите ветку **main**, папку **/ (root)** и нажмите **Save**.
7. После завершения публикации откройте ссылку на сайт в разделе **Settings → Pages**. Этой ссылкой можно поделиться с участниками занятия.

Загружайте содержимое распакованной папки: GitHub не распаковывает ZIP-архив вместо вас. Создавайте отдельный репозиторий, чтобы не заменить другой сайт с файлом `index.html`.

Официальная справка: [загрузка файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) · [настройка GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Как открыть на своём компьютере

Откройте `index.html` двойным щелчком. Изображение `staircase.png` должно оставаться в той же папке. Установка программ, подключение к интернету и отдельная сборка не требуются.

## Управление

- Наведение на ступень открывает описание.
- Нажатие закрепляет карточку, чтобы её было удобно читать.
- Крестик, клавиша **Esc** или нажатие за пределами карточки и ступеней закрывают описание.
- С клавиатуры: **Tab** выбирает уровень, **Enter** закрепляет карточку.
- На телефоне нажмите на название уровня под изображением.

## Как обновить текст

В файле `index.html` найдите строку `const levels = [`. Для каждого уровня указаны заголовок (`title`), вводное пояснение (`subtitle`) и три пункта (`items`). После правки загрузите обновлённый `index.html` в тот же репозиторий и сохраните изменения: GitHub Pages опубликует их автоматически.

## Если страница не открылась

Проверьте, что `index.html` и `staircase.png` лежат рядом в выбранной для публикации папке. Имена файлов должны совпадать точно, включая строчные буквы. Если публикация завершилась ошибкой, её подробности доступны во вкладке **Actions** репозитория.
